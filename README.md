# Smart Billing System

Smart Billing System is a Spring Boot backend application designed to manage restaurant billing operations efficiently. It follows a layered architecture with Controller, Service, Repository, and Entity layers.

## Features
- Menu item management (Add, View, Update, Delete)
- Order creation and processing
- Billing calculation logic
- RESTful API design
- Layered architecture (Controller, Service, Repository, Entity)
- Spring Data JPA integration

##  Technologies Used
- Java
- Spring Boot
- Spring Web (REST APIs)
- Spring Data JPA
- MySQL
- Maven
- HTML & CSS

## Project Structure

Controller Layer → Handles API requests
Service Layer → Business logic
Repository Layer → Database operations (JPA)
Entity Layer → Database entities


## Configuration
- Update database credentials in `application.properties`
- Configure MySQL database before running the project

##  How to Run
1. Clone the repository  
2. Open the project in an IDE (IntelliJ / Eclipse / VS Code)  
3. Update MySQL configuration  
4. Run `SmartBillingSystemApplication`  
5. Access APIs via Postman or browser

## Use Case
This project is suitable for learning:
- Spring Boot backend development
- REST API design
- JPA & database interaction
- Real-world billing system architecture
